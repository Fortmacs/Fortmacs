Elisp and Fortran, side by side

A real function in both: delete-space--internal, which deletes the spaces and tabs around point for M-\ (delete-horizontal-space), from Emacs's simple.el and from Fortmacs's port of it. Hover over (or tap) any part of either version to see its counterpart in the other.

Fortran takes more lines, about twice as many, but the extra lines buy something: every variable is declared with its type and intent, so the compiler catches mistakes; each step runs in the order it is written, whereas Lisp works from the inside out, so its order of reading is not its order of running (here delete-region is written first but runs last, after both positions are worked out, and a plain let binds its variables all at once, so one cannot use another: the starred let* exists to bind them one by one); and every error is checked where it can happen.

Fortmacs is GNU Emacs rewritten in Fortran.

Every closing parenthesis on the left lights up with the construct it closes.
