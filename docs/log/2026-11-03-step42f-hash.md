2026-11-03 — Step 42f, chunk 5: the message digests of fns.c and the Gnulib digests they use (`step42f-hash`, on `step42f-strings`).  Five new modules port Gnulib in pure Fortran, one per file as the timefns_mod/strftime precedent: md5_mod (lib/md5.c), sha1_mod (lib/sha1.c), sha256_mod (lib/sha256.c, SHA-224 and SHA-256), sha512_mod (lib/sha512.c, SHA-384 and SHA-512, with u64.h's `u64plus` as `add_unsigned`) and sha3_mod (lib/sha3.c, SHA3-224 to SHA3-512: Emacs 31.1's `secure-hash` lists them, so they are ported too).  Each has a context type whose default initialization is upstream's `*_init_ctx` (SHA-224 and SHA-384 are the SHA-256 and SHA-512 types made with `state=SHA224_INITIAL_STATE, digest_size=...`; SHA-3's with `digest_size=`), the type-bound `%process_bytes` and `%finish`, the private `process_*_block` and a pure `compute_*` function (upstream's `*_buffer`).  Fortran has no unsigned type: 32-bit words live in int64 masked with `iand`, rotations are `ishftc(x, n, 32)` (or plain `ishftc` on 64-bit lanes), logical right shifts `ishft`, and SHA-512's 64-bit sums are added as two 32-bit halves so no signed arithmetic overflows; the constants are `int(z'...', int64)` copied from upstream by script.  The steps are loops over tables instead of upstream's unrolled macros.  fns_mod gains, in the new submodule fns_hash_mod (it uses coding_mod and fileio_mod, which sit above fns_mod), `md5` and `secure_hash` as generics over a string and a buffer handle (`call secure_hash(algorithm, object, hash, status, beginning, end, binary)`), the algorithm a named constant `SECURE_HASH_MD5` … `SECURE_HASH_SHA3_512`, `secure_hash_algorithms` (their array), `buffer_hash` (SHA-1 over both sides of the gap), and the internals `extract_data_from_string`/`extract_data_from_buffer` (fns.c's extract_data_from_object: a string encoded by the most preferred coding system, or `raw-text` when unibyte, START/END then indexing the encoded bytes as upstream; a buffer's text encoded by the coding system `write-region` would choose, through `select_safe_coding_system_function`, recording `last_coding_system_used`), `compute_secure_hash` (fns.c's static secure_hash) and `digest_to_hex` (hexbuf_digest, make_digest_string).  Deferred: `secure-hash`'s `iv-auto` OBJECT (a naming question), subr.el's `sha1`.  Tests: test_md5_mod, test_sha1_mod, test_sha256_mod, test_sha512_mod, test_sha3_mod (the RFC 1321/FIPS 180/FIPS 202 known answers: the empty message, "abc", the 448-bit and 896-bit messages, a million "a"s; and the same digest from bytes fed in pieces of every size from 1 to 300); test_fns_mod ports test-secure-hash and fns-tests-hash-buffer and adds range, buffer, BINARY, coding-system and error tests.
