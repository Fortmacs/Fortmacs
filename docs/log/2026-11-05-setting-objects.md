2026-11-05 — Buffer-local procedure settings become setting objects (`setting-objects`, panel 14, the first long-name PR; builds on `spell-out-words`, #292).  The settings that were a bare procedure pointer plus free procedures (`X_set_local`, `current_X`, `is_X_local`, `X_clear_local`, `set_X`) are now setting objects with type-bound procedures, `call x%set_local(f)`, `f => x%get_current()`, `x%is_local()`, `call x%clear_local()`, the global value in `x%procedure` (R6-37).  The old free procedures are gone, with no aliases.

New module buffer_local_setting_mod (not a port): the abstract `buffer_local_setting_type` keeps the serial numbers of the buffers with their own value and finds, makes (reusing a closed buffer's entry, as `buffer_serial_live` allows) and clears entries; each extension (one per procedure interface, since Fortran has no generic procedure pointer component) holds `procedure` and `locals` and binds `set_local`, `get_current` and the deferred `append_local_entry` and `clear_local_entry`.  A buffer's own value wins even when null (upstream's local nil).  The setting is a module variable, never a registry element, so growing its arrays does not move `self` (hazard R not hit).

Converted from free procedures: `blink_matching_check_function`, `show_parenthesis_data_function`, `font_lock_fontify_region_function` (new object; default `font_lock_default_fontify_region`), `skeleton_transformation_function`, `skeleton_filter_function`, `skeleton_pair_filter_function`, `skeleton_further_elements`, `skeleton_pairs` and `skeleton_default_pairs` (`%pairs`, `%append`), `simple_merge_resolve_function`, `electric_indent_characters` (`=` sets the global array, so init.f90 keeps `electric_indent_characters = [10]`), `spellcheck_generic_check_word_test_function` (new object; now cleared by kill-all-local-variables as upstream's defvar-local), `log_view_expanded_log_entry_function` (new object), and smie--hanging-eolp-function as `simple_minded_indentation_engine_hanging_line_test_function`.  Rebased on the same parent for one word per meaning (`%value` → `%procedure`, `%current` → `%get_current`): `fill_paragraph_function`, `adaptive_fill_function`, `forward_expression_function`, `beginning_of_subprogram_function`, `css_class_list_function`, `css_id_list_function`, `comment_indent_function`, `syntax_propertize_function`, `add_log_current_subprogram_function`, `add_log_buffer_file_name_function`, `ansi_color_apply_face_function`, `indent_region_function`, the three `index_menu_*_function` settings, `revert_buffer_function`, `buffer_stale_function`, the three pcomplete function variables (their name-keyed shared storage is gone) and the five Isearch function variables (their docstrings moved from the types to the variables, so C-h v shows them).  The data settings' binding `current` (shell feature tables, `index_menu_patterns`, `font_lock_defaults`, `syntax_parser_state_table`) is `get_current` too (verb first, R6-17), and the settings' predicate binding `local_p` is `is_local` (`_p` → `is_*`, rule-decided; tools/fortran-names.d/2026-11-05-setting-objects).

Left as they are: `tabulated_list_entries` (a value-or-function variable that is always buffer-local and lives in tabulated_list's per-buffer record with its siblings; reported as an open question), comint's per-buffer functions and the abbrev table (per-buffer state, survey family 6).

Tests: test_buffer_local_setting_mod (new: per-buffer `set_local`/`get_current`/`is_local`, a local null, `clear_local`, entry reuse after closing a buffer, the array setting); test_skeleton_mod follows the new calls.
