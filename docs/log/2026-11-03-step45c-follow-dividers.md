2026-11-03 — Step 45c: Follow mode and Window Divider mode (`step45c-follow-dividers`).  Window Divider mode (frame.el, in frame_mod's new submodule frame_cmds_mod) sets the divider widths of the frame and of new frames as typed frame parameters (`frame_parameters_type`: a frame's own `parameters`, `default-frame-alist` as `default_frame`); a terminal frame only stores them and draws no dividers, so `frame-right-divider-width`, `frame-bottom-divider-width`, `window-right-divider-width` and `window-bottom-divider-width` (ported with window.h's macros) stay 0, as upstream on a tty.  `window-divider-default-places` is an integer setting with `WINDOW_DIVIDER_DEFAULT_PLACES_BOTTOM_ONLY`, `_RIGHT_ONLY` and `_BOTTOM_AND_RIGHT` (upstream's t).  Follow mode (follow.el, new follow_mod) aligns the windows of the selected window's chain before each redisplay and selects a window showing point; its commands are on C-c . and it remaps `end-of-buffer`.
