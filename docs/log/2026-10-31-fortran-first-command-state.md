2026-10-31 — Fortran-first command state (`fortran-first-command-state`, the owner's decision A7): the command loop's command state is `type(command_type), pointer` compared with `associated()`, and the prefix argument a `prefix_arg_type`.  `this_command`, `current_minibuffer_command` (callint_fm), `last_command`, `real_this_command`, `real_last_command`, `last_repeatable_command` (keyboard_fm), repeat_fm's `repeat_previous_repeated_command` and minibuffer state, and every saved copy are pointers; comparisons with a command name became `associated(p, commands%NAME)`.  The command loop resolves a key's binding once with callint_fm's `command_of` (repeat_fm's private copy is gone); `call_interactively` is generic over a command object and a binding.  Where upstream stores a keyboard macro in the state (a key bound to a macro, `call-last-kbd-macro`, `kmacro-call-macro`), the owner's A7a applies: `command_type` has a new `events` component, and the state points at keyboard_fm's `last_macro_command` (set with `set_last_macro_command`, named by its events' array constructor), whose procedure executes the events once as repeat.el does, so C-x z after C-x e repeats the macro (it failed with a wrong-type error before; new test repeat-keyboard-macro); lisp_fm's value types moved above `command_type` for the component.  Names that upstream puts in `this-command`/`last-command` but are no commands become null where nothing compares with them (undo-start, kill-region-dont-append, mode-exited, yank's t) and typed module objects where something does (`mark_subprogram_back`, `comment_line_backward`); comparisons with commands that are not ported (isearch-yank-pop, hilit-yank) are left out with a note; repeat's check for `mode-exit`, which nothing sets, is gone.  `prefix_arg`, `current_prefix_arg`, `last_prefix_arg`, eval_fm's `hook_current_prefix_arg` and every procedure taking a raw prefix argument (the scroll and recenter commands, `undo`, `yank`, `set_mark_command`, `cycle_spacing`, `beginning_of_buffer`/`end_of_buffer`, `set_fill_column`, `indent_for_tab_command`, `insert_tab`, the abbrev and kmacro commands, `isearch_repeat_*`, `execute_kbd_macro`, `end_kbd_macro`, `call_last_kbd_macro`, `execute_extended_command`) take a `prefix_arg_type` (`%kind` PREFIX_NONE, PREFIX_NUMBER, PREFIX_RAW or PREFIX_MINUS, and `%value`); the helpers `make_count` (isearch), `make_int` (comint), `prefix_is_16` (bookmark) and repeat's `prefix_numeric_value_of` are gone.  Help shows a command pointer by its command's name or null() and a prefix argument as `prefix_arg_type(kind=PREFIX_RAW, value=4)` (tools/gen-docstrings.sh); `intern_command_names` now also names every built-in command object.  tools/intrinsics.awk has a new rule, command-state, which rejects these variables declared as a `value_type`.  Events as an `event_type` (the rest of A7) wait for the owner's choice of the type's components.
