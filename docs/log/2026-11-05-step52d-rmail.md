2026-11-05 — Step 52d: the Rmail core (`step52d-rmail`).  New modules rmail_mod (rmail.el), rmail_summary_mod (rmailsum.el), rmail_output_mod (rmailout.el), rmail_edit_mod (rmailedit.el), rmail_keywords_mod (rmailkwd.el) and movemail_mod (lib-src/movemail.c, in Fortran inside Fortmacs).  \[rmail] visits `rmail_file_name` as an mbox file with no conversion, moves new mail from the inboxes (`rmail_primary_inboxes`, MAIL or the user's file in `rmail_spool_directory`) through movemail (a movemail program found on the search path, as rmail-autodetect does, or movemail_mod's lock file INBOX.lock, made by linking a temporary file, copy, fsync and emptying), adds the attribute header and shows the first unseen message in Rmail mode: the header pruned by `rmail_ignored_headers` (or `rmail_displayed_headers`), the body decoded by its charset and content transfer encoding, ">From " lines unquoted, the From and Subject fields highlighted, the counts and labels in the mode line.  As upstream, the message collection is swapped with a hidden viewer buffer, for which buffer_mod now ports buffer-swap-text (`swap_buffer_text`, with interval_tree_mod's `swap_buffer_overlays` and window_mod's `reset_window_markers`), and saving writes the collection through file_input_output_mod's new `write_region_annotate_functions`.  Ported commands: n p M-n M-p j < > . / t M-s C-c C-w d C-d u x s q b g i, the summary (h, C-M-h, C-M-l, C-M-r, C-M-f and Rmail Summary mode's commands, its post-command update of the Rmail window), output (o, C-o, w), editing (e, C-c C-c, C-c C-]) and labels (a, k, C-M-n, C-M-p).  multilingual_environment_mod ports coding-system-from-name and canonicalize-coding-system-name (charset names of messages); system_dependent_mod adds fsync, a sleep and the change time of a file (movemail's stale locks).  Deferred (docs/status/rmail_mod.md and the other status files): rmailmm.el (MIME messages are shown as other messages: `rmail_enable_mime` is .true. as upstream but no MIME function is set), RFC 2047 decoding (rfc2047.el: the header shown, summary lines, the by-regexp and by-topic summaries, simplified subjects), replying, forwarding and the other mail commands (they need compose-mail's extra arguments and message.el, step 52c), Babyl files, POP and IMAP, sorting, set-buffer-multibyte (the collection stays multibyte, its raw bytes as eight-bit characters: same positions, same bytes on disk), mail-mbox-from (so C-o of a shown message is a `void_function` error condition until time-date.el's date-to-time is ported).  Tests: test_rmail_mod (ports rmail-tests.el), test_rmail_summary_mod (ports rmailsum-tests.el in part), test_rmail_keywords_mod, test_rmail_edit_mod, test_rmail_output_mod and test_movemail_mod (own), with test_rmail_support_mod's sample mbox; buffer-tests.el's test-buffer-swap-text-1 and -2 in test_interval_tree_mod and an own swap test in test_buffer_mod.
