2026-11-05 — Spell out words (`spell-out-words`, owner decisions).  Every name spells out its abbreviated words, as the owner decided on 2026-11-05: the ordinary words of the survey (dir → directory, pos → position, prev → previous, arg → argument, buf → buffer, cur → current, str → string, idx → index, msg → message, tmp/temp → temporary, ...), the words of Fortran intrinsics in names (char → character, len → length, int → integer, min/max → minimum/maximum, abs → absolute, stat → status; the intrinsics, their keywords, `iso_fortran_env` and `iso_c_binding` names stay), regexp and `re_` → regular_expression, flyspell and ispell → the spellcheck family, and ppss → parser_state, capf → completion_at_point_function, begv/zv → beginning/end_of_accessible_portion, bol/eol/bob/eob, dwim → do_what_i_mean, hex → hexadecimal, kbd → keyboard, sync → synchronize, rev → revision, ws → whitespace, sym → symbol, nil → false ("diff" stays).  A command's procedure is `execute_X` (cmd_X), a module's one-time setup `initialize_X` (init_X), an error code `X_CODE` (FM_X: `QUIT_CODE`, `ARITHMETIC_ERROR_CODE`).  Standards and POSIX names keep their abbreviations (iso, ascii, utf, html, css, xml, json, f90, sgml, terminfo, smtp, ...; pid, uid, gid, fd, errno, getenv, mkdir, chmod, ioctl), and so do the fields of the Linux structures src/sys hardcodes (`tv_sec`, `tm_min`, `pw_dir`, `ws_row`, `stx_*`).  No aliases.

The renames are tools/fortran-names.d/2026-11-05-spell-out-words: 132 `word`, 7 `part` and 2 `prefix` entries, 108 `name` entries and 75 `keep` entries; about 5,000 identifiers changed (1,105 command procedures, 232 setup routines, 39 error codes).  tools/fortran-names-lib.awk gained the three new kinds: a `word` renames code and the names written in text (a word with an underscore; in a comment an upper-case or quoted argument name), never plain prose, prompts, messages or the program text of tests; a `part` is never a whole one-part name (the intrinsic: `part len length` renames `old_len`, not `len(x)`); a `prefix` renames the first part of a longer name.  An entry's new name that holds another entry's old word is renamed again (0-base's `auto_coding_regexps` is `auto_coding_regular_expressions`), so citations give the same Fortran names as the code.  A word means what it abbreviates where the survey's spelling would misread (decided by the no-abbreviations rule): cat is category (coding and completion categories), auth authentication (auth-source.el, SMTP AUTH), sig a signature in coding_mod and SMIE, dst daylight saving time in time_functions_mod, rev reversed in four files, ws the window list of the window tests, the winsize structure, a window start and a word start; variables that hold a command are `command_X`; init-file names are `initialization_file`.
