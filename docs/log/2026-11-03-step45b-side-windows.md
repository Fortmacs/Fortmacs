2026-11-03 — side windows (roadmap step 45b, `step45b-side-windows`): a new submodule of window_mod, window_sides_mod, ports window.el's side windows: the `window-side`, `window-slot`, `no-other-window` and `no-delete-other-windows` parameters as typed components of `window_type` (`WINDOW_SIDE_NONE`/`_LEFT`/`_TOP`/`_RIGHT`/`_BOTTOM`), `ignore-window-parameters`, the options `window-sides-vertical`, `window-sides-reversed` (`WINDOW_SIDES_REVERSED_NO`/`_YES`/`_BIDI`) and `window-sides-slots` (an array indexed by the side constants, `WINDOW_SIDES_SLOTS_UNLIMITED` for nil), `window-main-window`, `walk-window-tree` (returning the windows), `window-with-parameter` for `window-side` (`window_with_side`), `window--sides-check`, and `display-buffer-in-side-window` (`DISPLAY_ACTION_IN_SIDE_WINDOW`) with the new table entries `side`, `slot`, `dedicated` and the numeric `window-height`/`window-width` forms.  A side window is dedicated `side` (`DEDICATED_SIDE`), which switch-to-prev-buffer, quit-restore-window and replace-buffer-in-windows keep.  split-window gained SIDE `above`/`left` (split_window_internal's `before`), the side window checks, `window-combination-resize` `side` (the new window takes space from the whole side combination through `window_resize_child_windows`) and the combination limit beside a side window; delete-window refuses the main window and picks the MRU window as get-mru-window does (no dedicated or no-other windows); delete-other-windows keeps side windows marked `no-delete-other-windows` and replaces only the main window; other-window skips `no-other-window` windows; both commands give upstream's "No other window(s) ..." messages.  Learned: a local variable named like a module constant in another case (`dedicated_side`, `DEDICATED_SIDE`) is the same name to gfortran; a private module procedure called only from a submodule is not emitted with external linkage by gfortran 13 (undefined reference at link time), so `window_resize_child_windows` is public.  Deferred: `window-toggle-side-windows` and window states, reversing or re-laying-out existing side windows when the options change, persistent parameters in window configurations, `display-buffer-alist`.  Naming questions (the `window-sides-slots` shape, the numeric entry names, window.el's noun-first helpers, `window_with_side`, how a frame prints) wait for the owner.
