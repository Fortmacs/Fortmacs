2026-11-04 — Generated modules made at build time (`generated-at-build`): by the owner's decision, src/commands_mod.f90, src/modes_mod.f90, src/face_table_mod.f90 and src/docstrings_mod.f90 are no longer committed (.gitignore; removed from the index).  New tools/build.sh runs their four generators when an input is newer than build/generated.stamp (or a file is missing), then fpm with its arguments (`build` by default; `test`, `run`, `install` as fpm's own).  tools/check.sh generates before the style checks (`--fix` always) and drops the comparisons with the committed copies; test-recompile.sh installs through tools/build.sh, and unported-commands.sh generates first.  The Guix job gains gawk for the generators; since it has no fprettify, gen-docstrings.sh now splits a procedure pointer's declaration string, the one line that passed 132 columns unformatted.  `fortmacs --recompile` is unchanged: it links init.f90 against the installed library and module files, built from the generated sources at install.  README, CLAUDE.md and PORTING.md (status rows, the docstrings convention, a design decision) describe the new build.
