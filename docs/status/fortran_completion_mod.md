## Ported

`fortran_completion_mode` (a buffer-local minor mode, off by default, with `fortran_completion_mode_hook`; M-x, or `call f90_mode_hook%prepend(turn_on_fortran_completion_mode)` in init.f90),
`turn_on_fortran_completion_mode`,
`get_component_completion_data` on the buffer's `completion_at_point_functions` while the mode is on (so M-TAB, C-M-i, completion-preview and icomplete show its candidates),
designators before `%`: names, `%` with blanks around it, subscripts and arguments in parentheses (`sessions(k + 1)%`), continuation lines, any case,
nothing in a comment or a character literal,
the candidates: the components and type-bound procedures (and generic bindings) of the designator's type and of its parent types,
the types: the current buffer's (its accessible portion, parsed again when it changes), then the project's .f90 files (only when the first name is not declared in the buffer; each file parsed again when its size or modification time changes; the files listed again once when a type is not found), then the configuration API's,
scopes: the variable visible at point (program units, subprograms and interface bodies),
fortran_declarations_mod's parser: derived-type definitions (`extends`, components of intrinsic and derived types, procedure pointer components, `procedure` and `generic` bindings), type declaration statements with `type(...)` and `class(...)`, `::` lists with initializations and array specifications, comments, semicolons and continuation lines,
fortran_completion_table_mod: the objects src/fortmacs.f90 gathers that are declared with a derived type, the types it gathers, and the types those reach (parent types, component types), with their public components and bindings (tools/gen-completion-table.sh, run by tools/build.sh)

## Deferred

parsing on the worker thread (the parsing is synchronous behind the caches: system_worker_mod's workers read subprocess output only, and carrying parse jobs needs a second kind of job and message),
the typed name matched in any case (candidates are in lower case and completion is case-sensitive unless `completion_ignore_case`),
`associate` names, `select type` guards and function results (`f(x)%`),
type declarations without `::`,
fixed-form source (.f, .for),
the accessibility of components and bindings in the buffer and the project's files (all are offered),
the types of modules outside the project (compiled .mod files, include paths)
